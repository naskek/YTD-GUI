Исправление зависания на этапе [Merger]

Что было:
- Для режима MP4 приложение передавало параметры кодирования через общий префикс
  --postprocessor-args "ffmpeg:...".
- Этот префикс применяется не только к VideoConvertor, но и к Merger.
- Поэтому обычное быстрое объединение потоков превращалось в полное кодирование
  видео через libx264. yt-dlp не показывает подробный прогресс ffmpeg, и GUI
  выглядел зависшим на 92%.

Что исправлено:
1. Для MP4 выбираются потоки AVC/H.264 + M4A/AAC сразу при скачивании.
2. Вместо перекодирования используется быстрое объединение/remux в MP4.
3. Добавлен --encoding utf-8, чтобы русские пути и названия не превращались в ����.

Проверка:
- Python-файл проходит py_compile.
- Формируемая команда не содержит --recode-video и --postprocessor-args.

Чтобы собрать приложение заново, замените app\mini_url_converter.py в проекте
этим файлом и запустите штатный скрипт сборки проекта на Windows.
